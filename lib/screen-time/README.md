# Screen time daemon

The countdown, the lock, the earning, and the ledger of a child install's screen time (`sudo omarchy-kids time`). Vendored from Jankees van Woezik's [omarchy-screen-time](https://github.com/jankeesvw/omarchy-screen-time) (MIT, see LICENSE) and adapted for kids mode: it runs as root under `/etc/omarchy/parent` and `/var/lib/omarchy/parent`, the parent password stands in for the PIN, the questions are grades 1 to 6, a set is `questions` for `minutes`, the bank is clamped at zero, school hours pause the countdown instead of locking, and every change writes the `status.json` the lock screen and Math time read. At zero budget the daemon lets the full-screen Math time plugin remain open for the whole set, but starts its one-minute post-unlock failsafe whenever that plugin is absent. Escape on that forced Math screen opens a parent-password prompt whose successful five-minute grant returns to the desktop. `bin/omarchy-kids-timed` is the daemon, `bin/omarchy-kids-time-client` the client, and `omarchy-kids time` the parent's command over it.

Run the tests with `python3 lib/screen-time/tests/test_core.py`.
