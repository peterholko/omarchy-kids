# Launcher icon artwork

Created with the built-in image-generation tool for Omarchy Kids. The generated square PNG was reduced to 512 × 512 with ImageMagick, preserving transparency. The icon is bundled locally and requires no network access.

## Final prompt

Use case: logo-brand. Asset type: a production Linux desktop application launcher icon, one square 1024x1024 PNG with genuine transparent alpha outside the icon. Create a polished, cute, coherent app-icon design for a cozy educational game for an 11-year-old. Style: clean illustrated sticker, rounded simple shapes, restrained soft shading, strong dark-plum outlines, a few large readable details, friendly eyes, professionally balanced. It must read clearly at 32px and 48px. Composition: one centered icon occupying about 84 percent of the canvas, with generous transparent safety margin and no clipped edges. Behind the subject use one large soft rounded-square pastel tile with rounded corners; all canvas outside this tile must be actually transparent. No words, letters, app names, watermark, mockup, surrounding UI, texture, drop shadow outside the tile, or checkerboard painted into the image. Not a contact sheet: exactly one finished icon. Game: Paw Post Typing, a cozy animal mail-delivery typing game. Subject: a smiling orange fox courier with big pointed ears and a cream muzzle, holding one large cream envelope with a clearly readable coral-pink paw-shaped wax seal. The fox wears a simple teal mail satchel strap. Focus on the head and paws holding the letter, not a full body. A pale sky-blue rounded-square tile is the backdrop. Colors: warm orange, cream, teal, coral pink, dark plum. Bold, simple silhouette; no scenery or extra animals.
